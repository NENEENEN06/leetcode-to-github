# 算法模式参考

用于帮助判断用户代码属于哪类算法、如何提炼"我的思路"与"总结"。判断时以用户实际代码为准，本文件只提供术语和特征。

## 双指针 / Two Pointers

- 特征：两个指针同向或相向移动，常用于有序数组、回文、去重、区间收缩。
- 常见题：两数之和 II、三数之和、盛最多水的容器、删除有序数组中的重复项。
- 易错：指针移动条件、去重时跳过重复元素、边界越界。

## 滑动窗口 / Sliding Window

- 特征：维护一个窗口的左右边界，随着条件扩张/收缩，求最长/最短满足约束的子数组或子串。
- 常见题：无重复字符的最长子串、长度最小的子数组、滑动窗口最大值。
- 易错：何时收缩窗口、窗口内统计量的更新顺序、返回长度还是内容。

## 二分查找 / Binary Search

- 特征：在有序或具有单调性的区间上缩小搜索范围，注意闭区间/开区间、`mid` 取法和边界更新。
- 常见题：搜索旋转排序数组、寻找峰值、分割数组的最大值。
- 易错：死循环（`left = mid` 与 `mid = (left + right + 1) / 2`）、`mid` 溢出、边界开闭。

## 哈希表 / Hash Table

- 特征：用映射做查找/计数/去重/记录下标，把 O(n^2) 降低到 O(n)。
- 常见题：两数之和、字母异位词分组、存在重复元素。
- 易错：重复键覆盖、用键还是值、是否需要按序输出。

## 动态规划 / Dynamic Programming

- 特征：问题可分解为重叠子问题，存在状态转移方程；常见类型有线性 DP、背包、区间 DP、状态机 DP。
- 常见题：爬楼梯、最大子数组和、打家劫舍、最长递增子序列、编辑距离。
- 易错：状态定义、初始化、转移方向、边界、空间优化时只保留必要的上一行/前两个值。

## 深度优先搜索 / DFS 与回溯 / Backtracking

- 特征：枚举所有可能，递归搜索并回溯撤销状态，常用于组合、排列、子集、棋盘、树/图遍历。
- 常见题：组合总和、全排列、N 皇后、岛屿数量、二叉树路径和。
- 易错：递归出口、去重、状态恢复、剪枝条件。

## 广度优先搜索 / BFS

- 特征：按层扩展，求无权图/网格的最短路径或最小步数，使用队列。
- 常见题：二叉树的层序遍历、腐烂的橘子、单词接龙。
- 易错：入队时标记已访问、记录层数、边界和障碍判断。

## 栈与队列 / Stack & Queue

- 特征：利用后进先出/先进先出处理匹配、单调性、递归模拟。
- 常见题：有效的括号、每日温度、逆波兰表达式求值、用栈实现队列。
- 易错：空栈访问、匹配顺序、单调栈中保存下标还是值。

## 链表 / Linked List

- 特征：指针操作，常用哑节点、快慢指针、翻转。
- 常见题：反转链表、环形链表、合并两个有序链表、删除倒数第 N 个节点。
- 易错：空节点/头节点处理、哑节点避免特判、快慢指针的起点和步长。

## 树 / Tree 与递归

- 特征：利用子树递归、遍历序（前/中/后/层）、二叉搜索树性质。
- 常见题：二叉树的最大深度、验证二叉搜索树、最近公共祖先、路径和。
- 易错：空节点、递归返回值含义、BST 范围传递。

## 图 / Graph

- 特征：邻接表/邻接矩阵建模，DFS/BFS/拓扑排序/并查集/最短路。
- 常见题：课程表（拓扑排序）、岛屿数量、网络延迟时间。
- 易错：环检测、访问状态（未访问/访问中/已访问）、连通分量。

## 贪心 / Greedy

- 特征：每步做局部最优选择，需说明贪心选择为何全局最优。
- 常见题：跳跃游戏、分发饼干、区间调度。
- 易错：排序依据、贪心正确性证明、反例。

## 前缀和 / 差分

- 特征：预处理区间和/区间修改，把区间查询降到 O(1)。
- 常见题：区域和检索、和为 K 的子数组、航班预订统计。
- 易错：前缀和下标偏移、负数与哈希表统计、差分还原。

## 位运算 / Bit Manipulation

- 特征：利用异或、与、移位、掩码处理整数集合、奇偶、去重。
- 常见题：只出现一次的数字、位 1 的个数、子集。
- 易错：符号位、移位溢出、优先级（建议加括号）。
